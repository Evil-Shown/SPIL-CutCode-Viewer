2.2 STRUCTURE OF THE PROGRAM 
 
The post-processor must generate a text file countering a number of piece programs equal 
to the number of different schemes to cut.   
A progressive number (e.g. %3 ) identifies each pro gram in the first line. The number of 
the piece program must be between 0 and 3000  (0<Pr ogram number<3000). Once the 
value of 2999 is reached, the counter starts from one. 
 
Each piece program is made up of: 
• A heading containing geometrical information on th e sheet, the number of sheets to 
cut, the ones already cut etc.  
• A call to carry out cuts followed by an upgrading of the counter for glass sheets 
already cut.  
• The list of all cuts to carry out

3.1.3.3 Shape geometry 
 
Each different shape in the cutting scheme is written only once in the piece program.   
Each shape is contained between two labels starting from N10. 
So, the first shape will be described between label s N10-N11, the second between N12-
N13, the third between N14-N15 and so on. 
In this example only one shape is present (repeated  4 times) therefore, only labels N10 
and N11 are used.

3.4 Sending the cutting program to the Numerical co ntrol  
 
The piece program is loaded to the Numerical Contro l using a Glaston application – 
INOUTCNC - that transfer the ISO program from PC to CNC. 
 
From any application is possible to call INOUTCNC p assing file name to transfer to CNC : 
INOUTCNC will start the transfer of the ISO program  and, at the end of the operation, will 
show a message about the result. 
 
Next rows show an example to call INOUTCNC application ( using Visual Basic IDE ) : 
 
Dim RetVal as double 
 
Const InOutExe$ ="C:\EASYCAD\INOUTCNC\INOUTCNC.EXE" 
const NamefileIso$ = "C:\EASYCAD\PIPPO.CUT" 
 
RetVal = Shell(InOutExe$ + chr(32) + NameFileIso$) 
 
 
Shell function runs an executable program and retur ns a Variant (Double) representing the 
program's task ID if successful, otherwise it returns zero.
