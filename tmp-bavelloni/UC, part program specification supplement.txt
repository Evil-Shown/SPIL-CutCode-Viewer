2. Low-E Glass (Left bottom reference) 
1) Grinding overlap Mode  
 
 
Here you can: 
-Eable the multiple  grinding  path  mode for a grind path bigger than the grind tool 
thickness 
To enable this management ,check the  Active Overlap Grinding Mode  
-Set the Grind tool thickness ,now is set at 20mm  
-Set the grind overlap between a grind path and the following for multiple grind path. The 
measure inserted means the MIMIMUM overlap between each grind path run and the 
other.Now is set at 1 mm 
-Center LowE Removal 



===== PAGE 10 =====
                                                                                                                                     
Version:A(Version Date:2014.07.23) 10/21 Glaston(Tianjin) Co.,Ltd 
 
This setting will work ONLY if with ACTIVE OVERLAP GRIND MODE (multiple grind path run). 
This  force the first grind path run  (no  matter if you have one or more path run) at the center of 
the cut path   
So that ,if you  set up 20 mm of multiple grinding ,this will be done at the center of the cut ,10 
mm inside of the shape cut  and 10 mm outside of the shape cut .if you set up 30 mm ,you will 
have two multiple grind path runs ,but the first one will be always 10 mm inside the shape cut 
and 10 mm outside the shape cut.If you need this path will be done all INSIDE the shape cut ,you 
have to UNCHECK this.

How to set   “multiple grind path” : 
Here under is explained how to manage the multiple grind path: From inside the software shape 
management,choose the LOWE shape family: 
 
In the shape parametric mesaure insertion ,you have new parameters: MLE_01, MLE_02, MLE_03, 
MLE_04  ,these are the measure of the grinding for each side of the shape . 
NOTE: If you need multiple grinding path run for square and retangulare pieces (linear cut)  ,you MUST 
use the LOW_E00  Shape , if you need normal grind for these kind of pieces,you can avoid this . 
 Furthermore you can choose all other LOWE shape family for any other kind of shapes.

EXAMPLE OF MULTIPLE GRIND PATH 
EXAMPLE 1 :  
If you need to cover 60 mm of grinding and you have a tool measure of 20  mm and an overlap  Grinding  
of 1 mm  ,you will have 4 grind path  because the first one has to be 10 mm inside the cut and 10 mm 
outside the shape cut and  each one has to be overlapped  MINIMUM  of 1 mm  between the other.The 
amount of grind overlap between each run is chosen automatically with the limitation of the minimum 
value.   
EXAMPLE 2 
Here is displayed the tool path with shapes with multiple grinding and rectangular pieces with normal 
one run grinding ,the RED and  FUCSIA line is the tool path,the GREEN line means that that path will be 
cut and not grinded

5)  Edge distance to recognize border 
 
 
 
We assume that we have to alternate grind runs  path  if one run  is located near the border of the 
glass, this to avoid grind tool  consumption  if the grind tool edge is exceed the glass border . 
This parameter  define  which grinding path is considered   inside/outside  the glass border  to send 
low pressure for tool grind depending how  far the tool is outside the border 
 



===== PAGE 21 =====
                                                                                                                                     
Version:A(Version Date:2014.07.23) 21/21 Glaston(Tianjin) Co.,Ltd 
 
 
      
The parameter    Edge distance to recognize border  define the border line according this 
parameter, For example: 
If grinding wheel locate glass edge outside 10mm, and this parameter is 5mm Then is defined  as border 
line. 
 If grinding wheel locate glass edge outside 4mm, and this parameter is 5mm Then is  defined  as inside 
line
